
# Ayoub Bougatia — Portfolio

My personal portfolio showcasing selected software engineering projects, technical skills, education, and experience.

**Live Website:** [ayoubbougatia.me](https://ayoubbougatia.me)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Features

- Responsive design
- Interactive spotlight background and cursor effects
- Hidden technology icons
- Project filtering
- Accessibility and reduced-motion support

## Run Locally

Clone the repository:

```bash
git clone https://github.com/1-veer/portfolio.git
cd portfolio
```

Start a local development server:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
